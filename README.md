## What is this?

A collection of **Django practice projects** built while learning the framework. Covers core concepts like models, views, templates, URL routing, forms, and the admin interface.

## Getting Started

```bash
git clone https://github.com/jaidevxr/Django.git
cd Django
pip install django
python manage.py runserver
```
